## 2026-10-26 — Dashboard rail, policies, heavy decisions

- **Fire signal = both mechanisms:** (1) a **"Needs attention" list** at the top of the rail, max 2–3 items (Stripe "Action required" idiom), and (2) a **status on every KPI tile** (ok / watch / critical) carried by text label + border/weight, never colour alone. **Tiles do not reorder** — fixed positions keep muscle memory; the attention list does the surfacing.
- **Rail scaling = collapsible sections.** Overview always open at the top; further sections (e.g. Team, Infrastructure, Growth) are born with the phase that unlocks them and can be collapsed. Inference log remains the last section.
- **Delegation policies = both:** a toggle in each policy-capable channel's header (Slack notification-settings idiom) **and** a summary settings page for Metis listing all policies (plus "Pause Metis for audit").
- **Heavy decisions = full-page overlay:** a document (term sheet, incident page, release doc) opens over the whole workspace; the workspace is dimmed behind it (scrim, not blur — glassmorphism is banned in the base workspace). Clock paused (GDD M1).
